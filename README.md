### 🌌 About Me

I'm a passionate software developer specializing in **WordPress & WooCommerce Engineering, Modern Web Applications (React & PWA), and AI-Powered Developer Utilities**. I focus on building high-performance, accessible, and RTL-friendly products.

- 🧩 **WordPress & WooCommerce Architect**: Engineering modern SaaS-style user portals, custom plugins, and seamless e-commerce experiences (such as *Palette Panel Lite*).
- ⚛️ **Modern Frontend & PWA**: Building interactive, lightning-fast web applications using React 19, Tailwind CSS, Vite, and SQLite/PHP.
- 🤖 **AI-Integrated Products**: Integrating LLMs, OCR vision, and voice inputs into daily workflow and financial tools (such as *Palette Personal Wallet*).
- 🌐 **RTL & Typography Specialist**: Creating native RTL enhancements and typography patches for developer tools (*Persian Font Plus for Hermes*, *Antigravity-RTL*).
- 📱 **Android & Kotlin**: Modernizing mobile apps with Jetpack components, Material Design 3, and Android 15 standards.
